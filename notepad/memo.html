메모를 불러오는 중입니다.

Claude로 작업한 세션을 골라 '작업 기록' 폴더에 새 페이지로 정리합니다.

친구가 자기 계정에 같은 기능의 메모장을 만들 수 있습니다. 아래 순서대로 하면 됩니다.

  1. 코드 파일을 받아 친구에게 보냅니다.
    아래 버튼을 누르면 이 메모장의 코드 파일(내-메모장.html)이 저장됩니다. 이 파일을 메신저나 메일로 친구에게 보냅니다.
  2. 친구가 claude.ai에서 새 대화를 엽니다.
    받은 파일을 대화에 첨부하고, 아래 글을 붙여넣어 보냅니다. 
    
          
    3. 
        
  3. Claude가 알려 준 링크를 엽니다.
    그 링크가 친구의 메모장입니다. 처음 쓸 때 저장, 파일 첨부, Claude 사용을 허용할지 묻는 창이 뜨면 허용합니다.
    4. 
        
  4. 구글 드라이브는 따로 연결합니다.
    드라이브 기능은 친구가 claude.ai 설정의 커넥터에서 Google Drive를 연결해야 쓸 수 있습니다.
    5. 
      

      
코드 파일에는 메모장의 기능만 들어 있습니다. 내 메모와 첨부 파일은 들어 있지 않습니다. 친구의 메모는 친구 계정에 따로 저장되어 서로 볼 수 없습니다.
