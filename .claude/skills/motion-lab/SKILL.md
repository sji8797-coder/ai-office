# 모션 실험실 확인하고 효과 넣기

'모션 실험실'은 사용자가 모아 둔 인터랙션 효과 모음 페이지다. 효과마다 시연, 작동 원리,
어디에 쓰나, 필요한 도구, 복사용 프롬프트가 있고, 쓰임새에 따라 묶음으로 나뉘어 있다.
화면을 만들 때는 이 페이지를 기준으로 효과를 고르고, 프롬프트에 적힌 값을 구현 기준으로 삼는다.

## 화면을 만들거나 고칠 때

1. **페이지 찾기.** `Artifact` 도구의 `action: "list"`로 제목이 `모션 실험실`인 내 아티팩트를 찾는다.
   없으면 이 스킬을 건너뛰고 한 줄로 알린다. URL은 저장소 파일, 커밋 메시지, PR에 적지 않는다.
2. **읽기.** `action: "read"`로 페이지를 읽는다. 페이지가 크므로 저장된 파일에서 필요한 부분만 찾아 읽는다.
   - 묶음 목록: `class="group"` 섹션의 제목과 설명
   - 효과별 쓰임새: 각 `class="fx"` 섹션의 `<dt>어디에 쓰나</dt>`
   - 구현 기준: 고른 효과의 `<pre id="p-...">` 프롬프트
3. **고르기.** 만드는 화면의 부품(버튼, 메뉴, 목록, 탭, 입력칸, 완료 알림, 숫자, 제목 글자)마다
   해당 묶음에서 쓰임새가 맞는 효과를 고른다. 페이지 맨 아래 "공통으로 지킬 것"을 따른다.
   특히 한 화면에 효과는 2가지까지, 글자 효과는 화면당 한 줄까지만 쓴다.
4. **넣기.** 고른 효과의 프롬프트에 적힌 시간, 곡선, 닫힐 때의 움직임, "동작 줄이기" 처리,
   화면 읽기 기능 처리를 그대로 구현한다. 그 프로젝트의 디자인 토큰과 기존 동작은 바꾸지 않는다.
   - 새 패키지가 필요한 효과(예: Skia, react-native-svg)는 설치 전에 사용자에게 먼저 묻는다.
5. **알리기.** 답과 작업 기록에 어떤 부품에 어떤 효과를 넣었는지 한 줄씩 적는다.
   맞는 효과가 없어 넣지 않은 부품이 있으면 그것도 적는다.

요청에 "모션 없이"가 있으면 효과를 넣지 않는다.

## "보관함 처리해줘"라고 할 때

페이지 맨 위 '인스타 보관함'은 사용자가 휴대폰에서 넣어 둔 게시글 링크와 화면 녹화다.
아티팩트 데이터베이스의 `inbox` 컬렉션에 문서로 있다.

1. `ArtifactData`(목록에 없으면 ToolSearch의 `select:ArtifactData`로 불러온다)로
   모션 실험실 URL의 `inbox` 컬렉션을 `list` 한다. `status`가 `new`인 문서만 처리한다.
2. 문서마다 `status`를 `working`으로 바꾼다. 쓸 때는 읽은 `version`을 `if_version`으로 넣는다.
3. `files[].id`가 있으면 `Artifact` 도구 `action: "read"`에 `path`로 그 id를 넣어 파일을 받는다.
   영상은 `ffmpeg`로 프레임을 뽑아 시간 표시와 함께 이어 붙인 사진으로 보고, 움직임의 순서와 속도를 잰다.
   링크(`url`)는 출처 기록용이다. 인스타그램은 이 환경에서 열리지 않으므로 링크만으로 내용을 짐작하지 않는다.
4. 페이지에 효과를 추가한다. 기존 효과와 같은 형식(시연, 작동 원리, 어디에 쓰나, 필요한 도구, 프롬프트)으로
   알맞은 묶음에 넣고, `NEW` 표시를 붙이고, 묶음 버튼의 개수와 묶음 카드도 함께 고친다.
   이미 있는 효과와 같으면 새로 만들지 않는다. 게시는 같은 URL로 하고, 게시 전에 최신 버전을 읽는다.
5. 문서를 결과에 맞게 고친다.
   - 추가함: `status: "done"`, `result`에 한두 문장, `anchor`에 새 효과 제목의 id(예: `h35-wave`)
   - 영상이 없어 못 함: `status: "need_video"`, `result`에 "화면 녹화를 첨부해 주세요."
   - 인터랙션 게시글이 아님: `status: "skip"`, `result`에 이유 한 문장
   - `updatedAt`은 지금 시각(밀리초)
6. 사용자가 지우라고 하지 않는 한 보관함 문서와 첨부 파일은 지우지 않는다.

## 하지 않는 것

- 사용자에게 인스타그램 아이디나 비밀번호를 묻지 않는다.
- 모션 실험실의 묶음 구조, 공통 규칙, 인스타 보관함을 요청 없이 지우거나 바꾸지 않는다.
